# Landing Page Proposals

Welcome to the design meeting! Here are 10 different landing page concepts for your academic site. Each takes a completely different visual approach while keeping the "human-as-a-library" API docs concept.

Browse them all, take notes, and let's discuss what resonates.

<div class="proposal-card">
<span class="tag">Canvas 2D</span>

### V1: Particle Collision
ATLAS-style event display. Animated particle tracks spiral from a central collision. Your research areas emerge as detector layers.

[View Proposal](/proposals/v1)
</div>

<div class="proposal-card">
<span class="tag">d3-force</span>

### V2: Graph Neural Network
The hero IS a live graph. Nodes = publications, skills, collaborators. Hover to explore. Your bio is the graph structure itself.

[View Proposal](/proposals/v2)
</div>

[View Proposal](/proposals/v3)
</div>
